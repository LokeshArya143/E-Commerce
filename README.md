# Rama Sarees

A responsive storefront for sarees and dresses. Open `index.html` locally or publish the repository with GitHub Pages.

## Before launch

- Change `WA_NUMBER` in the page script to the shop's WhatsApp number (country code + digits).
- Replace the address, phone, hours, social links, and sample customer reviews.
- Confirm all sample products, prices, quality notes, images, and availability against real inventory.
- The owner portal is a browser-local prototype. Use server-side authentication and a database for a live catalog.
